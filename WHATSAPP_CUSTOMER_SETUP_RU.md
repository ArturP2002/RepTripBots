# RepTrip: подключение WhatsApp Cloud API

Пошаговая инструкция по созданию доступа к WhatsApp Cloud API в Meta и подготовке данных для запуска и тестирования бота.

**Время:** обычно 30–60 минут (если сайт Meta открывается и SMS приходят сразу).  
**Результат:** номер WhatsApp для бота и токены доступа.  
**Не входит в эту инструкцию:** написание кода, установка сервера и настройка webhook — это выполняется на стороне интеграции после сбора данных ниже.

---

## 1. Важно заранее

1. Это **не** обычное приложение WhatsApp Business на телефоне. Нужен кабинет **Meta for Developers** и продукт **WhatsApp Cloud API**.
2. Подойдёт **корпоративный или личный Facebook-аккаунт** администратора (лучше корпоративный email).
3. Для пилота можно начать с **тестового номера Meta** (бесплатно). Для реальных пользователей позже лучше подключить **боевой бизнес-номер**.
4. Токены и секреты храните и передавайте **только в защищённом канале** (не в открытых чатах и письмах без защиты).
5. Если сайты Meta не открываются — включите VPN и повторите шаги.

Ссылки:
- Meta Business: https://business.facebook.com  
- Meta for Developers: https://developers.facebook.com  

Не используйте кабинет **Meta VR / Horizon** (`developers.meta.com` про VR) — там WhatsApp API нет.

## 2. Meta Business

### 2.1. Вход в Meta Business
1. Откройте https://business.facebook.com
2. Войдите через Facebook.
3. Если Business Portfolio ещё нет — создайте (название компании или проекта, например `RepTrip`).

### 2.2. Права доступа
Убедитесь, что у аккаунта роль **Admin** этого Business Portfolio.  
При необходимости позже можно добавить коллег или технических специалистов как Admin / партнёров.

---

## 3. Приложение в Meta for Developers

### 3.1. Создание приложения
1. Откройте https://developers.facebook.com
2. Меню **My Apps** → **Create App**.
3. Выберите тип **Business** (или сценарий для бизнеса).
4. Укажите:
   - **App name:** например `RepTrip WhatsApp`
   - **Contact email:** рабочий email
   - **Business portfolio:** созданный в разделе 2
5. Нажмите **Create app**.

### 3.2. Подключение продукта WhatsApp
1. В панели приложения откройте **Add products** / каталог продуктов.
2. Найдите **WhatsApp** → **Set up**.
3. Откройте раздел **WhatsApp → API Setup** (иногда называется Getting started).

На этом экране находятся почти все нужные данные.

---

## 4. Номер WhatsApp

Есть два варианта. Для быстрого теста достаточно **варианта 1**. Для работы с реальными пользователями предпочтителен **вариант 2**.

### Вариант 1 — тестовый номер Meta (быстрый старт)
1. В **API Setup** Meta уже показывает тестовый номер (часто вида `+1 555 …`).
2. Покупать номер не нужно.
3. На тестовом номере можно писать **только номера из списка разрешённых**.
4. Добавьте в список (**To** / Manage phone number list) все номера участников теста.
5. Каждый номер подтверждается кодом из SMS / WhatsApp.

### Вариант 2 — бизнес-номер (боевой режим)
1. Подготовьте номер в международном формате, например `+7700………`.
2. Номер **не должен** быть уже зарегистрирован в обычном WhatsApp (иначе его нужно сначала отвязать от WhatsApp / WhatsApp Business на телефоне).
3. В API Setup добавьте и зарегистрируйте номер (**Add phone number**).
4. Пройдите подтверждение по SMS или звонку.
5. Дождитесь статуса, что номер активен для Cloud API.

Если Meta запросит верификацию бизнеса (документы компании) — это нормально для боевого режима. Для первого теста можно остаться на варианте 1.

## 5. Какие данные сохранить

На экране **WhatsApp → API Setup** найдите и сохраните:

| № | Параметр | Как выглядит | Назначение |
|---|----------|--------------|------------|
| 1 | **Access Token** (временный или постоянный) | длинная строка, часто начинается с `EAA…` | доступ бота к API |
| 2 | **Phone number ID** | длинное число (это **не** `+7…`) | ID номера в API |
| 3 | **WhatsApp Business Account ID (WABA ID)** | длинное число | учётная запись WhatsApp Business |
| 4 | **Display phone number** | например `+1 555 0100` или `+7700…` | номер, на который пишут пользователи |
| 5 | **App ID** | число в настройках приложения | идентификация приложения |
| 6 | **App Name** | например `RepTrip WhatsApp` | название приложения |

### Про токен
- **Temporary access token** действует около **24 часов** — только для короткого теста.
- Для устойчивой работы нужен **постоянный токен** (System User) — см. раздел 6.

---

## 6. Постоянный Access Token (рекомендуется)

1. Откройте https://business.facebook.com → **Business settings**.
2. Раздел **Users → System users**.
3. **Add** → создайте System User (имя, например, `reptrip-bot`), роль **Admin**.
4. У этого пользователя: **Generate token** / Generate new token.
5. Выберите приложение `RepTrip WhatsApp`.
6. Отметьте права (permissions):
   - `whatsapp_business_messaging`
   - `whatsapp_business_management`
7. Сгенерируйте токен и **сразу скопируйте** — повторно целиком его часто не показывают.
8. В **Accounts → WhatsApp accounts** выдайте этому System User доступ к WhatsApp Business Account.

Именно этот токен предпочтителен для конфигурации бота.

---

## 7. Чеклист подготовки

1. Создать Business + App + WhatsApp (разделы 2–3).
2. Выбрать тестовый или боевой номер (раздел 4).
3. Добавить в allowlist номера всех участников теста (если используется тестовый номер Meta).
4. Сохранить параметры из таблицы (раздел 5).
5. По возможности создать постоянный token (раздел 6).
6. Заполнить итоговый шаблон (раздел 8).
7. Не удалять приложение и доступы до завершения настройки интеграции.

Webhook (URL вида `https://…/webhooks/whatsapp`) настраивается на стороне сервера бота. В кабинете Meta может потребоваться указать Callback URL, Verify token и подписаться на поле **messages**.

- [ ] Есть Phone number ID и Display phone number

## 10. Частые проблемы

| Проблема | Что сделать |
|----------|-------------|
| Не открывается developers.facebook.com | VPN, другая сеть; не путать с VR-кабинетом Meta |
| Не приходит SMS с кодом | другая сеть/SIM; подождать 5–10 минут; проверить международный формат номера |
| Нет ответа на сообщение с «чужого» номера | добавить номер в allowlist тестового From |
| Temporary token перестал работать | сгенерировать новый или сделать постоянный System User token |
| Номер нельзя добавить в Cloud API | он уже занят в WhatsApp на телефоне — отвязать или взять другой |
| Meta просит верификацию бизнеса | для теста — тестовый номер Meta; для боя — пройти верификацию |

---

## 11. Что происходит после сбора данных

1. Параметры вносятся в конфигурацию бота.
2. Поднимается публичный HTTPS URL.
3. В Meta App подключается webhook (Callback URL + Verify token + подписка на `messages`).
4. Для проверки используются:
   - номер WhatsApp бота;
   - команда вида `JOIN ……`;
   - или ссылка на страницу выбора канала.

Сценарий агента проходит в WhatsApp; подтверждение встреч владельцем в пилоте выполняется в Telegram.

## Безопасность

Не публикуйте Access Token в открытых чатах, тикетах и скринах без маскирования.
